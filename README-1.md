# Harx — النشر على استضافة مجانية (Supabase + Cloudflare Pages)

## الخطوات (حوالي 20 دقيقة)
1. **Supabase:** اعمل حساب مجاني على supabase.com ← New project (اختار منطقة في أوروبا) ← احفظ كلمة سر القاعدة.
2. **القاعدة:** افتح SQL Editor ← الصق محتوى `supabase.sql` كله ← Run. لازم يخلص بدون أخطاء.
3. **المفاتيح:** Project Settings ← API. انسخ **Project URL** و**anon public key**. افتح `index.html` بأي محرر نصوص وابحث عن `PASTE_SUPABASE_URL` و`PASTE_ANON_KEY` وحط القيمتين مكانهم.
   - ⚠️ حط الـ anon key بس. ممنوع تحط `service_role` في أي ملف.
4. **الإيميل:** Authentication ← Providers ← Email. لو مش عايز تأكيد بالإيميل وقت التجربة اقفل Confirm email (والأفضل تسيبه مفتوح بعدين).
5. **الرفع:** Cloudflare Pages ← Create ← Direct Upload ← ارفع مجلد فيه `index.html` فقط. هيدّيك رابط. (بدائل مجانية: Netlify Drop أو GitHub Pages.)
6. **أول دخول:** افتح الرابط وسجّل حسابك **أنت أولاً**: أول حساب بيبقى المالك تلقائياً. بعدها Authentication ← URL Configuration ← حط رابط موقعك في Site URL.
7. **الموظفين:** من تبويب «الموظفين» (للمالك) اكتب اسم الموظف وإيميله وكلمة سر مؤقتة ودوره واضغط «إنشاء الحساب». سلّمه البيانات وهيدخل من نفس الرابط. لو طلب تأكيد إيميل اقفل Confirm email من Authentication ← Providers ← Email. نسيان كلمة السر: Authentication ← Users في Supabase.

## اللي اتحل
- مفيش حد أقصى 500 فاتورة (بيتحمّل كل شيء على دفعات).
- زر **نسخة احتياطية** (للمالك فقط، أعلى الشاشة) بينزّل ملف JSON بكل البيانات. اعمله أسبوعياً وخزّنه برا.
- لو موظفين سجّلوا دفعات على نفس الفاتورة في نفس اللحظة: الدفعتين بيتحفظوا. وقاعدة البيانات بترفض مجموع دفعات أكبر من الإجمالي.
- أي حساب جديد مفيش له وصول لحد ما المالك يفعّله (محمي من القاعدة نفسها).

## حدود لازم تعرفها
- Supabase المجاني بيوقف المشروع بعد حوالي أسبوع بدون استخدام. لو المحل هيتقفل مدة، ادخل المشروع من لوحة Supabase وفعّله بعدين. راجع حدود الخطة الحالية على موقعهم لأنها بتتغير.
- إخفاء الأسعار والأرباح عن الاستقبال والفني بيتم في الواجهة. القاعدة بتمنع غير المسجّلين وبتخلّي «مشاهدة فقط» قراءة بس، لكن موظف تقني مفعّل ممكن يوصل للبيانات. فعّل بس اللي تثق فيهم.
- بيانات النسخة اللي على claude.ai مش هتنتقل لوحدها.
- لسه مفيش: تعديل الفاتورة بعد الحفظ، واسترداد مسجّل عند الإلغاء، وترقيم فواتير تسلسلي.
